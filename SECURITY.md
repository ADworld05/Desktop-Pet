# Security reports

Do not publish credentials, personal chat/memory or an exploit against somebody else's files in a public issue. Before disclosing details, contact the repository maintainer through an available private GitHub channel. A dedicated private-reporting channel has not yet been configured.

Use a minimal synthetic reproduction. Include the affected version, impact and steps; remove private paths and data. No formal response-time guarantee or security certification is offered.

The app's intended boundaries are fixed local model inference and explicitly scoped desktop actions; no unrestricted shell execution, elevation or security-policy bypass. Code signing, when available, identifies a publisher and does not prove the absence of defects.
